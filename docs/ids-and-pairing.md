# Определение ID и автопривязка

## Ручной способ (curl)

### Telegram group ID

1. Добавьте бота в группу и отправьте любое сообщение.
2. Выполните:

```bash
curl -s "https://api.telegram.org/bot$TG_BOT_TOKEN/getUpdates"
```

Ищите поле `chat.id` (обычно `-100...` для супергруппы).

### MAX group ID

```bash
curl -sS -H "Authorization: $MAX_BOT_TOKEN" https://platform-api.max.ru/chats
```

Ищите `chat_id` нужной группы.

## Автопривязка через /connect

Теперь можно не искать ID руками.

Важно: команды `/connect` и `/disconnect` принимаются только от администраторов группы.

1. В TG-группе отправьте:

```text
/connect Самолёт
```

2. В нужной MAX-группе отправьте ту же команду:

```text
/connect Самолёт
```

3. После второй команды бот завершит связку и отправит в обе группы:

```text
Связь установлена.
```

Файл связей будет обновлён автоматически в `state/connectors.json`.

## Отключение связи

Если нужно разорвать связь, администратор отправляет:

```text
/disconnect
```

Команда отключит связь для текущей группы (TG или MAX).
Также поддерживается явный вариант:

```text
/disconnect Самолёт
```
